# Glow by Vandna Sharma – Makeover & Studio

Premium, mobile-first beauty studio website built with Next.js and Tailwind CSS.

## Local setup

1. Install dependencies

```bash
npm install
```

2. Start the local development server

```bash
npm run dev
```

3. Open the site in your browser

```text
http://localhost:3000
```

## Production build

```bash
npm run build
```

Then run the production server:

```bash
npm run start
```

## Useful commands

```bash
npm run dev
npm run build
npm run start
npm run lint
```

## Deployment options

- Recommended: Vercel
- Alternative: any Node.js hosting platform compatible with Next.js

## SEO notes
